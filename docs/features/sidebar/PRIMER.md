# Sidebar (CA-36)

## Purpose

Provide a fixed Admin navigation rail that persists across all protected pages.

## Scope

- Fixed left sidebar, full height, `240px` wide
- Top wordmark area
- Five primary navigation items with icons
- Active and hover visual states
- Lower utility area for Admin-only actions and sign-out

## Routes

- `/dashboard`
- `/submissions`
- `/scouts`
- `/crm`
- `/pipeline`
- `/templates`
