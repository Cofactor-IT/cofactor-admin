# Sidebar (CA-36)

## Purpose

Provide a fixed Admin navigation rail that persists across all protected pages.

## Scope

- Fixed left sidebar, full height, `240px` wide
- Top wordmark area
- Primary navigation items with icons
- Active and hover visual states
- Lower utility area for IT-only actions and sign-out

## Routes

- `/dashboard`
- `/submissions`
- `/scouts`
- `/crm`
- `/pipeline`
- `/templates`

## Utility Actions

IT users also see:

- `Team Members`
- `Audit Log`

All users see:

- `Sign Out`
